# Bento Social Media Dashboard

A modern responsive social media dashboard built with pure HTML and CSS using a Bento-style layout.

This project focuses on creating a clean and modern UI while practicing advanced CSS techniques such as CSS Grid, Flexbox, Custom Properties, and Responsive Design.

## 🎨 Design Approach

The project was built with a component-based mindset:

- Reusable CSS variables
- Organized CSS architecture
- BEM class naming methodology
- Separation of layout and component styles
